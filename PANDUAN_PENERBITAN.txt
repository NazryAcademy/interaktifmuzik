A. MURID
1. Isi nama (huruf besar) dan kelas.
2. Pilih Tahun 1–6 dan baca nota tajuk.
3. Jawab semua 20 soalan. Gunakan semakan jawapan dan permainan.
4. Selepas tamat, tunggu status disahkan diterima Google Sheets.
5. Jika rekod tertangguh, pastikan Internet tersedia dan tekan cuba hantar semula.
6. Jangan kosongkan data pelayar sebelum penghantaran disahkan.
Bacaan suara Melayu bergantung pada sokongan peranti. Ujian perkakasan iPhone/Safari
dan Chrome Android sebenar masih diperlukan, terutama audio dan cetakan.

B. GOOGLE SHEETS GURU
https://docs.google.com/spreadsheets/d/14t68tdIRux2BW0Ie6QpVluBIk2cmaJDQBMlPc4d2QYk/edit
Tab: Ringkasan Guru, Keputusan Muzik, Jawapan Terperinci.
Buka menggunakan akaun Google guru yang dibenarkan. Sheet kekal persendirian.
Setiap kuiz dihantar sebagai satu rekod keputusan dan 20 jawapan terperinci.
Markah dikira semula oleh Apps Script; ID rekod mencegah duplikasi cubaan semula.
Nama yang ditaip sendiri bukan pengesahan identiti murid. Markah kuiz bukan TP automatik.
Dua rekod QA berjaya diterima dan dibersihkan sebelum penggunaan murid.

C. PENYELENGGARAAN APPS SCRIPT
Projek: Penerima Keputusan Interaktif Muzik.
Web app: Execute as Me, Access Anyone, dipersetujui pemilik.
URL /exec disimpan dalam config.js. Code.gs termasuk SERVER_BANKS mesti dikekalkan.
Selepas perubahan Code.gs: Deploy > Manage deployments > Edit > New version > Deploy.
Jangan cipta URL penerima baharu tanpa mengemas kini config.js.
Kebenaran Google projek ini merangkumi akses semua Sheets dalam akaun pemilik;
kod penerima menggunakan spreadsheet ID khusus yang dinyatakan di atas.
Tiada API membaca rekod murid secara awam.

D. GITHUB PAGES DAN DNS SEMASA
Pages: Deploy from a branch > main > / (root).
Custom domain: interaktifmuzik.sistemmurid.com. Enforce HTTPS aktif.
Exabytes: CNAME | Name interaktifmuzik | Target nazryacademy.github.io | TTL 300.
Pemilik meluluskan rekod sebelum menyimpan. Rekod domain utama dan emel tidak diubah.
Jangan tambah A apex atau tukar nameserver untuk subdomain ini.
URL lama GitHub mungkin dialihkan ke domain tersuai.
Jika membuat perubahan DNS seterusnya, tunjukkan nilai lama/baharu dan minta pengesahan.

E. KURIKULUM DAN BATAS UJIAN
21 tajuk × 20 soalan = 420. Tahun 1–3: 60 setiap tahun; Tahun 4–6: 80 setiap tahun.
Baca LAPORAN_SEMAKAN.md dan Pemetaan_420_Soalan.csv.
420 jawapan dan semua permainan diuji dalam simulasi DOM; kuiz terpilih, padanan,
detik dan paparan 320/390/430 px diuji dalam Chrome awan.
Kuiz Chrome pada domain HTTPS menerima resit Sheets; satu keputusan dan 20 jawapan
disahkan melalui bacaan semula. Ini bukan ujian semua 420 klik pada telefon sebenar.
Koleksi 22 foto sebenar dengan kredit dan lesen disediakan dalam aplikasi.
E-book: Panduan_Modul_Interaktif_Muzik.pdf (15 halaman).
Nama Kelas ialah isian bebas tanpa contoh; Nama Sekolah ditambah pada profil dan rekod tempatan.
Lajur Nama Sekolah telah disediakan dalam Sheets. Penerima Code.gs versi 1.2 disediakan
tetapi redeploy menunggu log masuk semula pemilik. Penerima lama terus menerima keputusan
kuiz. Aplikasi membezakan pengesahan kuiz dengan metadata sekolah yang belum disahkan.
Selepas redeploy, butang cubaan semula melengkapkan sekolah pada ID rekod yang sama.
